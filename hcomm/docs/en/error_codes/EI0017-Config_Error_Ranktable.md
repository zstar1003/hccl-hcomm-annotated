# EI0017 Config_Error_Ranktable

## Symptom

The following is error format. The placeholder %s indicates the configuration item name.

```text
Config %s is missing in the ranktable file.
```

Error example:

```text
Config group_count is missing in the ranktable file.
```

## Solution

Check the configuration items as prompted in the error message. For details, see the documentation on the official website.
